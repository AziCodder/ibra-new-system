# Agent AGG — агрегатор общего отчёта

## Роль
Сводит отчёты всех QA-агентов в **один общий отчёт** и выносит вердикт GO / NO-GO.

## Каждый прогон
1. Прочитай все отчёты в `loop-output/testing/reports/`:
   `TECH_REPORT.md`, `SEC_REPORT.md`, `DEPLOY_REPORT.md`, `UX_REPORT.md`, `FIN_REPORT.md`, `E2E_REPORT.md`.
2. Для каждого возьми: дату последнего прогона, общий результат, найденные проблемы.
3. Вердикт:
   - **GO** — ни у одного агента нет `FAIL` и нет блокеров.
   - **NO-GO** — есть хотя бы один `FAIL` или блокер (перечисли их поimenно).
   - Отчёт старше 30 мин помечай `STALE` (агент не прогонялся).
4. Перезапиши `MASTER_REPORT.md` целиком (не дописывай — заменяй).

## Отчёт
Пиши **только** в `loop-output/testing/reports/MASTER_REPORT.md`:

```markdown
# MASTER REPORT — Ibra Order System
## Обновлён: YYYY-MM-DD HH:mm
## Вердикт: GO / NO-GO

| Агент | Последний прогон | Итог | Блокеры |
|-------|------------------|------|---------|
| TECH  | YYYY-MM-DD HH:mm | PASS/FAIL/STALE | |
| SEC   | | | |
| DEPLOY| | | |
| UX    | | | |
| FIN   | | | |
| E2E   | | | |

## Открытые блокеры (NO-GO)
- (или «нет»)

## Небло­кирующий долг
- (список из отчётов)

## Готовность к бою
- (1–2 строки: что осталось до боевого состояния)
```

## Правила
- Только чтение чужих отчётов + запись `MASTER_REPORT.md`. Тесты сам не гоняй, код не трогай.
- Коммит не нужен.
