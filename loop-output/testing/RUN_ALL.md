# RUN ALL — запуск всех QA-агентов в loop

Запускает **6 тест-агентов параллельно** + **1 агрегатор**, сводящий все проверки в один общий отчёт `reports/MASTER_REPORT.md`.

Каждый агент = отдельный `/loop` в **своей** сессии/терминале (7 сессий). Все читают только свой файл-инструкцию и пишут только свой отчёт — они не мешают друг другу.

---

## Карта агентов

| Агент | Что проверяет | Инструкция | Отчёт | Sentinel |
|-------|---------------|------------|-------|----------|
| TECH   | pytest, tsc, eslint, регресс | `AGENT_TECH.md`   | `reports/TECH_REPORT.md`   | `AGENT_LOOP_TICK_TECH` |
| SEC    | роли, валидация, prod-config, security | `AGENT_SEC.md` | `reports/SEC_REPORT.md` | `AGENT_LOOP_TICK_SEC` |
| DEPLOY | health, CI, Docker prod, smoke | `AGENT_DEPLOY.md` | `reports/DEPLOY_REPORT.md` | `AGENT_LOOP_TICK_DEPLOY` |
| UX     | empty/loading/error, адаптив, роли в UI | `AGENT_UX.md` | `reports/UX_REPORT.md` | `AGENT_LOOP_TICK_UX` |
| **FIN**  | **мультивалюта, курсы, остатки, прибыль** | `AGENT_FIN.md` | `reports/FIN_REPORT.md` | `AGENT_LOOP_TICK_FIN` |
| **E2E**  | **сквозной сценарий в браузере, роли UI** | `AGENT_E2E.md` | `reports/E2E_REPORT.md` | `AGENT_LOOP_TICK_E2E` |
| **AGG**  | **сводит всё в один общий отчёт** | `AGENT_AGG.md` | `reports/MASTER_REPORT.md` | `AGENT_LOOP_TICK_AGG` |

> Жирным — новые агенты, закрывающие пробелы риск-карты (расчёты + e2e + единый отчёт).

---

## Запуск

Открой 7 сессий Claude Code (по одной на агента) и вставь в каждую соответствующую команду.
Формат: `/loop <интервал> <промпт>`. Один тик = один прогон по инструкции агента.

```text
# 6 тест-агентов — интервал 10 минут
/loop 10m Прочитай loop-output/testing/AGENT_TECH.md целиком и выполни ровно один прогон: сделай проверки и полностью перезапиши reports/TECH_REPORT.md. Ничего кроме своего отчёта не меняй.
/loop 10m Прочитай loop-output/testing/AGENT_SEC.md целиком и выполни ровно один прогон: сделай проверки и полностью перезапиши reports/SEC_REPORT.md. Ничего кроме своего отчёта не меняй.
/loop 10m Прочитай loop-output/testing/AGENT_DEPLOY.md целиком и выполни ровно один прогон: сделай проверки и полностью перезапиши reports/DEPLOY_REPORT.md. Ничего кроме своего отчёта не меняй.
/loop 10m Прочитай loop-output/testing/AGENT_UX.md целиком и выполни ровно один прогон: сделай проверки и полностью перезапиши reports/UX_REPORT.md. Ничего кроме своего отчёта не меняй.
/loop 10m Прочитай loop-output/testing/AGENT_FIN.md целиком и выполни ровно один прогон: сделай проверки и полностью перезапиши reports/FIN_REPORT.md. Ничего кроме своего отчёта не меняй.
/loop 10m Прочитай loop-output/testing/AGENT_E2E.md целиком и выполни ровно один прогон: сделай проверки и полностью перезапиши reports/E2E_REPORT.md. Ничего кроме своего отчёта не меняй.

# агрегатор — интервал 15 минут (со сдвигом, чтобы читать уже свежие отчёты)
/loop 15m Прочитай loop-output/testing/AGENT_AGG.md целиком и выполни ровно один прогон: сведи все отчёты и полностью перезапиши reports/MASTER_REPORT.md. Ничего кроме этого отчёта не меняй.
```

---

## Как читать результат

Смотри только один файл — **`reports/MASTER_REPORT.md`**:
- **Вердикт GO** — все агенты PASS, блокеров нет → можно в бой.
- **Вердикт NO-GO** — есть FAIL/блокер, они перечислены поимённо.
- Строка `STALE` у агента = его loop не прогонялся >30 мин (проверь его сессию).

## Правила для всех агентов
- Один тик = один прогон = один перезаписанный отчёт. Не накапливать историю в отчёте.
- Никаких правок кода и коммитов — только свой `*_REPORT.md`.
- Дата/время в отчёте — из системных часов (`Get-Date`).
- Нашёл баг → фиксируешь в отчёте (файл/строка/сценарий), исправление — отдельная задача разработки, не в loop.
